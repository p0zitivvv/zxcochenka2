# 🔧 Настройка глобального счётчика голосов

Для того, чтобы счётчик "Всего голосов" показывал сумму всех голосов на всех устройствах, нужно настроить глобальное хранилище данных.

## Вариант 1: JSONBin.io (Рекомендуется)

### Шаги настройки:

1. **Зарегистрируйтесь на [jsonbin.io](https://jsonbin.io/)** (бесплатно)

2. **Создайте новый bin:**
   - Нажмите "Create Bin"
   - Вставьте пустой JSON объект: `{}`
   - Сохраните

3. **Получите API ключ:**
   - Перейдите в Settings → API Keys
   - Скопируйте "Master Key"

4. **Обновите `script.js`:**
   - Найдите константу `GLOBAL_STORAGE_CONFIG`
   - Замените `binId` на ID вашего bin (из URL)
   - Вставьте ваш API ключ в `apiKey`

```javascript
const GLOBAL_STORAGE_CONFIG = {
    binId: 'ваш-bin-id', // Замените на ваш bin ID
    apiUrl: 'https://api.jsonbin.io/v3/b',
    apiKey: 'ваш-api-ключ' // Вставьте ваш Master Key
};
```

### Пример:
Если URL вашего bin: `https://jsonbin.io/abc123/def456`
То `binId` будет: `abc123/def456`

---

## Вариант 2: Без настройки (только чтение)

Если вы не хотите настраивать API ключ, сайт будет работать с локальным хранилищем (localStorage). Голоса будут сохраняться только на каждом устройстве отдельно.

Для полной синхронизации между устройствами нужен API ключ.

---

## Как это работает:

- ✅ При загрузке страницы данные загружаются из глобального хранилища
- ✅ При голосовании данные сохраняются локально и отправляются на сервер
- ✅ Каждые 10 секунд данные автоматически синхронизируются
- ✅ Если сервер недоступен, используется локальное хранилище

---

## Альтернативные варианты:

Если JSONBin.io не подходит, можно использовать:
- **Firebase Realtime Database** (бесплатный тариф)
- **Supabase** (бесплатный тариф)
- **GitHub Gist API** (требует токен)

Для настройки других сервисов нужно будет изменить функции `loadGlobalVotes()` и `saveGlobalVotes()` в `script.js`.
