# zxcochenka2
# 🔥 FaceOff - Кто круче?

Современный веб-сайт для сравнения людей по фотографиям. Голосуйте за участников и смотрите рейтинг!

## 🚀 Быстрый старт

Просто откройте `index.html` в браузере или загрузите на GitHub Pages.

### Локальный запуск

1. Клонируйте репозиторий
2. Откройте `index.html` в браузере
3. Готово! 🎉

### GitHub Pages

1. Загрузите файлы в репозиторий
2. Включите GitHub Pages в настройках репозитория
3. Выберите корневую папку
4. Сайт будет доступен по адресу `https://username.github.io/repository-name`

## ✨ Функционал

- 🗳️ **Голосование** - Выбирайте между двумя фотографиями
- 👆 **Свайпы** - Свайпайте карточки как в Tinder (поддержка touch и mouse)
- 📊 **Рейтинг** - Топ участников с количеством голосов
- 💾 **localStorage** - Все голоса сохраняются локально
- 🔒 **Защита от повторного голосования** - Нельзя проголосовать за одну пару дважды подряд
- 📱 **Адаптивный дизайн** - Отлично работает на всех устройствах
- 🎨 **Современный UI** - Минималистичный дизайн с плавными анимациями

## 📁 Структура проекта

```
/project
├── index.html      # Страница голосования
├── rating.html     # Страница рейтинга

```

## 🛠️ Технологии

- HTML5
- CSS3 (Flexbox, Grid, Animations)
- Vanilla JavaScript (ES6+)
- localStorage API

## 🎯 Особенности

- **Свайпы**: Поддержка touch-событий для мобильных устройств и mouse-событий для десктопа
- **Анимации**: Плавные переходы и анимации свайпов
- **20 участников**: Готовые данные с placeholder-фото от Unsplash
- **Легко расширяемо**: Просто добавьте новых участников в массив `people` в `script.js`

## 📝 Как добавить участников

Откройте `script.js` и добавьте в массив `people`:

```javascript
{ id: '21', name: 'Новое Имя', image: 'URL_к_фото' }
```
